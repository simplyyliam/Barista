# Performance 0.4b-final

Measured 2026-11-12 with `pnpm bench 0.4b-final` (release build, nothing else started).

| What | Result | Budget | |
|---|---|---|---|
| Idle CPU (avg) | 0.04% | < 0.5% | ok |
| CPU with one item updating every second | 0.02% | < 0.5% | ok |
| Connect + hello to welcome | 1.7 ms | < 100 ms | ok |
| item.create until it is in the registry (median / worst of 30) | 0.1 / 0.5 ms | < 100 ms | ok |
| item.update (label) until it is in the registry (median / worst of 30) | 0.1 / 0.3 ms | < 100 ms | ok |
| item.setMenu until it is in the registry (median / worst of 30) | 0.1 / 0.3 ms | < 100 ms | ok |
| Menu pick until the app gets menu.click (median / worst of 30) | 0.1 / 0.6 ms | < 20 ms | ok |
| Click to popover.show reaching the app (median / worst of 30) | 0.5 / 0.9 ms | < 20 ms | ok |
| Click on the open icon to popover.hide reaching the app (median / worst of 30) | 0.1 / 1.3 ms | < 20 ms | ok |
| Click to menu window visible (median / worst of 10) | 32.6 / 35.0 ms | < 50 ms | ok |
| Memory, private (bar + WebView2) | 130 MB | < 120 MB | over |
| Memory, working set sum (reference) | 490 MB | counts shared pages | ok |
| Memory growth over 8 h | not measured | < 5 MB | |

- 8 processes counted (the bar and its WebView2 children), 12 logical cores.
- CPU: total over 33 s after 10 s of settling, divided by cores. The ticking row is the same with `examples/test-client` running (one label update per second).
- Latency is measured over the pipe with a minimal client: the time from sending the message until `debug.listItems` shows it. The UI sees it about one frame (16 ms) later, because `items-changed` is coalesced; the render time is the UI's.
- Popovers: from the click (sent over the pipe as `debug.click`) until the app receives `popover.show` / `popover.hide`. Window visible and focused is timed with a real mouse click by `scripts/popover-latency.ps1`.
- Menus: the window time is from the click (sent over the pipe as `debug.click`) until Windows reports the menu window visible; React drawing the entries comes on top once the UI exists.
- Machine: AMD Ryzen 5 7430U with Radeon Graphics, 15 GB RAM.
